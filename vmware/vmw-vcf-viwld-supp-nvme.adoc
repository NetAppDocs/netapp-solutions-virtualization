== Deployment workflow for adding vVols NVMe datastores as supplemental storage in a workload domain
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ../media/

[.lead]
Get started with adding NVMe/TCP vVols datastores as supplemental storage for a VMware Cloud Foundation (VCF) workload domain. You'll review the deployment requirements, set up an NVMe/TCP-enabled SVMs and LIFs, configure vSphere host networking, and deploy the NVMe/TCP datastore.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png[One]link:vmw-vcf-viwld-supp-nvme-requirements.html[Review the deployment requirements]
[role="quick-margin-para"]
Review the requirements to deploy NVMe/TCP datastore in a VMware Cloud Foundation workload domain.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png[Two]link:vmw-vcf-viwld-supp-nvme-svm-lifs.html[Create the SVM and LIFs and the NVMe namespace]
[role="quick-margin-para"]
Create a storage virtual machine with logical interfaces and the NVMe namespace for NVMe/TCP traffic.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png[Three]link:vmw-vcf-viwld-supp-nvme-network.html[Configure networking]
[role="quick-margin-para"]
Create distributed port groups and vmkernel adapters on the vSphere hosts for the VCF workload domain.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png[Four]link:vmw-vcf-viwld-supp-nvme-storage.html[Configure storage]
[role="quick-margin-para"]
Deploy the NVMe/TCP datastore.
