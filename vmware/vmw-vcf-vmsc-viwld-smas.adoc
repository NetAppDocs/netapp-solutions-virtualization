= Configure a stretch cluster for a workload domain using SnapMirror active sync (SAN and NAS)
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ../media/

[.lead]
In this use case we outline the procedure to configure a stretch cluster for a workload domain using SnapMirror active sync with ONTAP tools for VMware vSphere (ONTAP tools 10.6 supports FC and iSCSI). ONTAP supports SnapMirror active sync both for SAN (with iSCSI, Fibre Channel, and NVMe over Fabrics) and NAS (NFSv3 and NFSv4.1).

image:vmw-vcf-vmsc-viwld-smas-001.png[Stretch cluster for VCF with SnapMirror active sync]

Both Uniform and Non-uniform stretched cluster configurations are supported for SAN. In case of NAS, it is active-passive configuration with ONTAP 9.19.1.

[NOTE]
====
Host proximity settings are used with multipath configuration to ensure the optimal path selection for the storage traffic. The host proximity settings are configured on igroup in case of SCSI and subsystem in case of NVMe-oF. For example, in Uniform host access configuration, host has access to both storage systems in the stretched cluster. In multipath configuration, the optimal and non-optimal paths are configured based on the host proximity settings.
====

== Scenario Overview

The datastores on VCF Workload domain can be protected with SnapMirror active sync to provide stretch cluster solution. The protection is enabled at datastore level (consistency group) for SAN and protected at SVM level for NAS.

// == Prerequisites

.Principal storage on Workload Domain
[%collapsible%open]
==== 
Workload domain can be created either by import or creation using the VCF Ops tool. 

. Create Workload domain with any supported protocol.
. link:https://docs.netapp.com/us-en/ontap-tools-vmware-vsphere-10/configure/add-vcenter.html[Register workload domain vCenter to ONTAP tools manager to deploy vCenter plugin]
. link:https://docs.netapp.com/us-en/ontap-tools-vmware-vsphere-10/configure/add-storage-backend.html[Register storage systems on ONTAP tools]
. For iSCSI and FC Datastores, Refer link:https://docs.netapp.com/us-en/ontap-tools-vmware-vsphere-10/protect/protect-multiple-ds.html[Protect the vSphere datastore with ONTAP tools]
. For NVMe-oF and NFS datastores, check the video demo below for the steps to protect the datastores on the workload domain with SnapMirror active sync.


====

.Supplemental storage on Workload Domain
[%collapsible%open]
==== 
Once the workload domain is up and running, additional datastores can be created and protected using ONTAP tools. For more details on SnapMirror active sync, refer https://docs.netapp.com/us-en/ontap/snapmirror-active-sync/index.html#benefits[Learn about ONTAP SnapMirror active sync]

TIP: With ONTAP tools 10.6 and later, you can protect the datastores on the workload domain with SnapMirror active sync. Refer the video demo below for the steps to protect the datastores on the workload domain with SnapMirror active sync.
====
