= Deployment workflow for converging vCenter server instance to VCF management domain with NFS datastores
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ../media/

[.lead]
Converge an existing vSphere cluster with NetApp ONTAP NFS datastores to a VMware Cloud Foundation management domain. You'll review configuration requirements, deploy ONTAP tools and provision NFS datastores, and use the VCF Installer Tool to validate and use your existing components, deploy required new components, and configure the platform.

This workflow is also applicable if ONTAP NFS 4.1 datastores are to be used as Principal Storage for the VCF management domain.

For an overview of the convergence process, refer to the VMware documentation: https://techdocs.broadcom.com/us/en/vmware-cis/vcf/vcf-9-0-and-later/9-1/deployment/converging-your-existing-vsphere-infrastructure-to-a-vcf-or-vvf-platform-.html[Converging Existing Virtual Infrastructure to a VCF].
