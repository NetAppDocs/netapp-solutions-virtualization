= Summary of Nutanix Cloud Platform with ONTAP storage
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ../media/

[.lead]
ONTAP provides a scalable and resilient storage platform for hosting Nutanix virtual machine workloads, enabling organizations to simplify storage management while optimizing capacity utilization, performance, and data protection.

By combining Nutanix compute with ONTAP storage, customers can leverage enterprise-class storage services, flexible data management, and seamless scalability while maintaining a consistent operational model. 

The process uses familiar storage concepts such as storage virtual machines (SVMs), FlexVol volumes, export policies, and NFS datastores, allowing administrators to deploy and manage storage using established ONTAP tools and procedures. This integration enables the Nutanix AHV hypervisor to benefit from the mature data services of ONTAP while providing a flexible and efficient infrastructure for virtualized environments.
